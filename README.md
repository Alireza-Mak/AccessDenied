## 🚀 About the Project  
**🎮 FPS Escape Game (Unity, C#)**

A first-person shooter built in **Unity** using **C#**, combining combat, exploration, and puzzle-solving mechanics. This project focuses on modular system design, clean architecture, and engaging gameplay.

The game includes:

**1.** Room-based exploration with locked doors and key progression  

**2.** AI enemies with attack behavior and dynamic difficulty  

**3.** Multiple weapons system (limited ammo + melee weapon)  

**4.** Explosive environmental objects (mines, gas tanks)  

**5.** Health and ammo pickup system  

**6.** Interactive UI with reusable pop-up system  

**7.** Global Escape system for menu navigation and game pause  

**8.** Difficulty settings affecting enemy range and explosion impact
